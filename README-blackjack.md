# 二十一點 (Blackjack) 遊戲

這是一個完整的單檔二十一點網頁遊戲。

## 如何使用

直接在瀏覽器中開啟 `blackjack.html` 即可開始遊戲。

## 功能特色

- ✅ 完整的二十一點遊戲規則
- ✅ 52 張牌組，使用 Fisher-Yates 洗牌演算法
- ✅ 智慧 Ace 處理（自動選擇 1 或 11 點）
- ✅ 莊家 AI（≤16 要牌，≥17 停牌）
- ✅ Blackjack（天然 21）偵測
- ✅ 完整的中文遊戲訊息記錄
- ✅ 響應式設計，支援桌面和行動裝置
- ✅ 無外部依賴，完全離線可用

## 遊戲規則

1. 點擊「開始新局」開始遊戲
2. 玩家和莊家各發兩張牌（莊家一張暗牌）
3. 玩家可選擇「要牌」或「停牌」
4. 莊家在 ≤16 點時必須要牌，≥17 點時停牌
5. 點數最接近 21 但不超過者獲勝
6. 超過 21 點即爆牌

## 技術細節

- 單一 HTML 檔案（包含 CSS 和 JavaScript）
- 使用 ES6+ JavaScript
- 支援 Chrome、Firefox、Edge 最新版本
- 無需伺服器，直接在瀏覽器開啟即可
